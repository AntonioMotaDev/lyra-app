# Lyra - v1.0

App web que incluye herramientas de metrónomo y afinador.

## Características

### Metrónomo Digital
- **Control de BPM**: Rango de 40 a 200 BPM con control deslizante
- **Subdivisiones**: Negras, corcheas, tresillos y semicorcheas
- **Interfaz Visual**: Indicador visual del beat actual

### Afinador 
- **Precisión en Cents**: Medición precisa de la desviación tonal
- **Compatibilidad**: Optimizado para guitarra (6 cuerdas) y bajo (4 cuerdas)
- **Feedback Visual**: Barra de afinación con código de colores
- **Notas de Referencia**: Visualización de afinación estándar

 etc.)


##  Requisitos Previos

- Node.js 18.0 o superior
- npm, yarn, pnpm o bun
